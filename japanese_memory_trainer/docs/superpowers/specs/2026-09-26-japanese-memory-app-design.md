# 일본어 장기기억 학습 앱 설계서

작성일: 2026-09-26
가칭: 기억 일본어
대상: JLPT N4 → N3 → N2 어휘를 오래 기억하기 어려운 학습자

## 1. 목표

이 앱의 성공 기준은 하루 문제 수가 아니라 `장기기억으로 판정된 단어 수`가 꾸준히 증가하는 것이다.
초기 사용자는 하루 신규 단어 5개로 시작하고, 개인 기억률이 안정되면 자동으로 신규 학습량을 늘린다.

## 2. 1차 버전 범위

- 메인 대시보드
- 오늘의 신규 단어 학습
- 자동 복습
- 위험 단어 자동 분류
- 일본어→한국어 문제
- 한국어→일본어 문제
- 문장 빈칸 문제
- 듣기형 문제를 위한 TTS 연결 구조
- 단어별 정답/오답/반응시간 저장
- 기억 단계 0~7 관리
- 다음 복습일 자동 계산
- 장기기억 단어 수 / 위험 단어 수 / JLPT 레벨별 진행률 통계
- 주간 보스전: 최근 자주 틀린 단어 집중 복습

1차 버전에서는 AI 회화, 클라우드 동기화, 사용자 계정, 광고, 결제는 제외한다.

## 5. 학습 흐름

### 신규 단어

1. 일본어/읽기/한국어 뜻/예문을 한 번 보여준다.
2. 잠시 뒤 일본어→한국어 선택 문제를 낸다.
3. 한국어→일본어 회상 문제를 낸다.
4. 문장 빈칸 문제를 낸다.
5. 정답 여부와 응답시간을 저장한다.

### 복습

오늘 날짜가 `nextReviewAt` 이상인 단어를 우선 출제한다.
위험 점수가 높은 단어는 일반 단어보다 먼저 출제한다.

## 6. 기억 단계와 복습 간격

초기 기준:

- Stage 0: 신규
- Stage 1: 10분
- Stage 2: 1일
- Stage 3: 3일
- Stage 4: 7일
- Stage 5: 14일
- Stage 6: 30일
- Stage 7: 60일 이상

정답이어도 응답시간이 너무 길면 단계 상승 폭을 줄인다.
오답이면 단계가 내려가며 위험 점수가 올라간다.

## 7. 답변 평가

사용자가 직접 선택할 수 있는 기억 감각:

- 몰랐음
- 힘들게 기억
- 기억함
- 바로 기억

자동 평가에 사용하는 값:

- 정답/오답
- 응답시간
- 최근 연속 정답 횟수
- 이전 오답 횟수
- 문제 방향: 일본어→한국어 / 한국어→일본어

한국어→일본어 성공에는 더 높은 기억 점수를 준다.

## 8. 위험 단어 판정

다음 조건을 조합해 dangerScore를 계산한다.

- 최근 오답
- 같은 단어 반복 오답
- 5초 이상 지연된 정답
- 일본어→한국어는 맞지만 한국어→일본어는 실패
- 장기 복습에서 실패

위험 단어는 홈 화면에 별도 개수로 표시하고 주간 보스전 후보가 된다.

## 9. 화면 구성

### 홈

- 연속 학습 일수
- 오늘 기억률
- 신규 단어 수
- 오늘 복습 수
- 위험 단어 수
- 오늘의 퀘스트 시작
- 장기기억 단어 수
- N4/N3/N2 진행률

### 학습

- 단어 카드
- 발음
- 뜻
- 예문
- 다음 버튼

### 복습

문제 유형을 섞어서 출제한다.
정답을 누르기 전에는 뜻을 보여주지 않는다.

### 위험 단어

틀린 횟수와 마지막 실패 날짜를 기준으로 정렬한다.

### 보스전

일주일 동안 가장 어려웠던 단어를 집중 출제한다.

### 통계

- 장기기억 단어 수
- 이번 주 새로 정착한 단어 수
- 기억률
- 위험 단어 수
- JLPT 레벨별 진행률

## 10. 초기 단어 데이터

1차 개발에서는 N4 중심 샘플 단어 50~100개를 앱 내부 데이터로 제공한다.
구조 검증 후 N4/N3/N2 데이터 세트를 분리해서 확장한다.

JLPT 공식 고정 어휘 목록을 전제로 하지 않고, 레벨 추정값과 사용빈도/중요도를 함께 저장한다.

## 11. 저장 방식

1차 버전은 로컬 저장을 사용한다.
앱 종료 후에도 기억 상태와 학습 기록이 유지되어야 한다.

DB 계층을 UI에서 분리해 이후 SQLite/Isar/Hive 등 실제 저장소로 교체할 수 있게 한다.

## 12. 오류 처리

- 데이터가 비어 있으면 학습 버튼 대신 안내를 표시한다.
- 저장 실패 시 학습 진행 기록을 잃지 않도록 예외를 잡고 사용자에게 알린다.
- 잘못된 stage 값은 0~7 범위로 보정한다.
- nextReviewAt 계산 실패 시 안전한 기본 복습 날짜를 사용한다.

## 13. 테스트 기준

- 신규 단어가 하루 제한 수 이상 나오지 않는지
- 오답 후 위험 점수가 증가하는지
- 한국어→일본어 정답이 더 높은 기억 점수를 받는지
- Stage별 nextReviewAt이 올바르게 계산되는지
- 앱 재실행 후 학습 상태가 유지되는지
- 오늘 복습 대상만 정확히 추출되는지
- 보스전이 최근 위험 단어를 우선 선택하는지

## 14. 구현 규칙

- 소스 주석에는 작성/변경 날짜 `2026-09-26`를 붙인다.
- 한 파일이 지나치게 커지지 않게 역할별로 분리한다.
- 학습 알고리즘은 UI 코드와 분리한다.
- 사용자에게 보여주는 핵심 숫자는 `총 문제 수`보다 `장기기억 단어 수`를 우선한다.

## 15. 1차 완료 조건

사용자가 앱을 실행하여 다음 흐름을 끝까지 사용할 수 있어야 한다.

`홈 → 오늘의 퀘스트 → 신규 5단어 → 복습 → 위험단어 확인 → 통계 확인`

그리고 앱을 종료 후 다시 실행해도 각 단어의 기억 단계와 다음 복습 일정이 유지되어야 한다.
