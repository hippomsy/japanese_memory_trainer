## 프로젝트 구성

핵심 Flutter 소스는 `lib/`, 자동 테스트는 `test/`에 있습니다.

이 작업 환경에는 Flutter SDK가 설치되어 있지 않아 `flutter test`, `flutter analyze`, Android APK 빌드는 여기서 실행하지 못했습니다. Flutter SDK가 설치된 개발 환경에서 이 폴더를 Flutter 프로젝트로 열고 플랫폼 폴더가 없는 경우 IDE의 Flutter 프로젝트 생성 기능으로 Android 플랫폼 파일을 생성한 뒤 `pubspec.yaml`과 `lib/`, `test/`를 그대로 사용하면 됩니다.

소스의 주요 클래스/함수 주석은 요청에 따라 `2026-09-26` 날짜를 포함합니다.
