# 第2回 問題4 (即時応答)
Q 1 | 23.9
L 25.9 | A | きょうは何で学校に来ましたか。 | 오늘은 뭘 타고 학교에 왔어요?
O 30.3 | | 1. 友達と二人で来ました。 | 친구와 둘이서 왔어요.
O* 35.3 | | 2. 地下鉄に乗ってきました。 | 지하철을 타고 왔어요.
O 40.1 | | 3. 勉強をしに来ました。 | 공부하러 왔어요.
EXP 「何で(무엇으로)」는 수단·교통편을 묻는 말입니다.

Q 2 | 55.0
L 56.9 | A | すみません、トイレはどこですか。 | 실례지만 화장실은 어디예요?
O 61.3 | | 1. いえ、大丈夫です。 | 아뇨, 괜찮아요.
O* 65.6 | | 2. あちらです。 | 저쪽이에요.
O 69.4 | | 3. さっき行きました。 | 아까 갔어요.

Q 3 | 84.0
L 86.2 | A | 週末は何かしましたか。 | 주말에는 뭐 했어요?
O 90.5 | | 1. じゃあ、カラオケに行きませんか。 | 그럼 노래방에 가지 않을래요?
O 95.7 | | 2. ショッピングがしたいです。 | 쇼핑하고 싶어요.
O* 100.2 | | 3. ずっと家にいました。 | 계속 집에 있었어요.
EXP 과거(しましたか)를 물었으니 과거형으로 답한 3이 정답입니다.

Q 4 | 114.8
L 116.9 | A | この部屋に入らないでください。 | 이 방에 들어가지 마세요.
O 120.8 | | 1. 失礼します。 | 실례합니다.

Q 5 | 142.8
L 144.8 | A | ジャンさんはもう起きましたか。 | 장 씨는 벌써 일어났어요?
O* 149.1 | | 1. はい、今シャワーを浴びています。 | 네, 지금 샤워하고 있어요.
O 154.7 | | 2. もう来ると思います。 | 곧 올 거예요.
O 159.1 | | 3. いえ、まだ寝ていません。 | 아뇨, 아직 안 잤어요.
EXP 일어났다는 근거(지금 샤워 중)를 말한 1이 정답. 3은 「まだ寝ています(아직 자고 있어요)」라면 맞지만 「寝ていません」이라 반대 뜻입니다.

Q 6 | 174.3
L 176.2 | A | 中田さん、今暇ですか。 | 나카타 씨, 지금 한가해요?
O* 180.6 | | 1. はい、どうしましたか。 | 네, 무슨 일이에요?
O 185.3 | | 2. ゲームをしたり、テレビを見たりします。 | 게임을 하거나 텔레비전을 보거나 해요.
O 191.3 | | 3. いいえ、そうじゃありません。 | 아니요, 그렇지 않아요.
EXP 「今暇ですか」는 부탁을 하려는 말이므로 「はい、どうしましたか」로 받습니다.
