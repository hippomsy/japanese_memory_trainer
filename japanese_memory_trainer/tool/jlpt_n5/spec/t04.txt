# 第1回 問題4 (即時応答)
Q 1 | 23.3
L 25.3 | A | マイケルさん、夏休みはいつまでですか。 | 마이클 씨, 여름 방학은 언제까지예요?
O 30.7 | | 1. 海で泳ぎます。 | 바다에서 수영해요.
O* 34.8 | | 2. 来週までです。 | 다음 주까지예요.
O 39.0 | | 3. 1か月くらいです。 | 한 달 정도예요.
EXP 「いつまで(언제까지)」에는 기한으로 답합니다. 3은 「どのくらい(얼마 동안)」에 대한 답입니다.

Q 2 | 53.5
L 55.3 | A | 映画はどうでしたか。 | 영화는 어땠어요?
O* 58.8 | | 1. 怖かったですが、面白かったです。 | 무서웠지만 재미있었어요.
O 64.4 | | 2. 映画館は広くてきれいでした。 | 영화관은 넓고 깨끗했어요.
O 69.6 | | 3. 映画よりドラマのほうが好きです。 | 영화보다 드라마를 더 좋아해요.
EXP 영화의 감상을 묻고 있으므로 영화 내용에 대한 느낌을 말한 1이 정답입니다.

Q 3 | 85.3
L 87.3 | A | 木村さん、あれは林さんの車ですか。 | 기무라 씨, 저건 하야시 씨 차예요?
O* 92.8 | | 1. いいえ、中山さんの車ですよ。 | 아니요, 나카야마 씨 차예요.
O 97.8 | | 2. 車に乗ったほうが早いですよ。 | 차를 타는 게 빨라요.
O 103.3 | | 3. そうです、私の車です。 | 맞아요, 제 차예요.
EXP '하야시 씨 차냐'는 질문에 다른 사람의 차라고 답한 1이 자연스럽습니다. 3은 「そうです」라고 하고 '제 차'라고 해서 모순입니다.

Q 4 | 118.5
L 120.7 | A | すみません、坂本さんはいますか。 | 실례합니다, 사카모토 씨 계세요?
O 125.7 | | 1. はい、とてもいい人です。 | 네, 아주 좋은 사람이에요.
O 130.4 | | 2. いえいえ、大丈夫ですよ。 | 아뇨아뇨, 괜찮아요.
O* 135.5 | | 3. ご飯を食べに行きました。 | 밥 먹으러 갔어요.
EXP 자리에 있는지 묻는 말에 '밥 먹으러 갔다(지금 없다)'고 답한 3이 정답입니다.

Q 5 | 150.3
L 152.2 | A | このラーメンは辛いですね。水をあげましょうか。 | 이 라멘 맵네요. 물 드릴까요?
O 158.1 | | 1. じゃあ、飲んでください。 | 그럼 마셔 주세요.
O 162.3 | | 2. そんなことないですよ。 | 그렇지 않아요.
O* 166.8 | | 3. すみません、お願いします。 | 고마워요, 부탁해요.
EXP 「〜ましょうか(〜해 드릴까요?)」라는 제안을 받아들일 때는 「お願いします」.

Q 6 | 181.8
L 183.7 | A | エマさん、1年にどのくらい国に帰りますか。 | 엠마 씨, 1년에 얼마나 고향에 돌아가요?
O 190.0 | | 1. いつも一人で行きますよ。 | 항상 혼자 가요.
O 194.6 | | 2. 来月の15日です。 | 다음 달 15일이에요.
O* 199.5 | | 3. 2、3回ですね。 | 두세 번이요.
EXP 「1年にどのくらい(1년에 얼마나)」는 횟수를 묻는 질문이므로 「2、3回」가 정답입니다.
