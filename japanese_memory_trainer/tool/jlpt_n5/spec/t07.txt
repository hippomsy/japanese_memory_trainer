O 36.4 | | 1. あの、靴売り場に行きましたか。 | 저기, 신발 매장에 갔어요?

Q 2 | 65.5
PIC 🕘📋 | 今日の会議が始まる時間を知りたいです。 | 오늘 회의가 시작하는 시간을 알고 싶습니다.
L 67.6 | ナ | 今日の会議が始まる時間を知りたいです。何と言いますか。 | 오늘 회의가 시작하는 시간을 알고 싶습니다. 뭐라고 말합니까?
O 74.7 | | 1. 会議をする時間がありますか。 | 회의할 시간이 있어요?
O 79.9 | | 2. 会議は何時までですか。 | 회의는 몇 시까지예요?
O* 84.7 | | 3. 会議は何時からですか。 | 회의는 몇 시부터예요?
EXP 시작 시간은 「何時から(몇 시부터)」, 끝나는 시간은 「何時まで(몇 시까지)」.

Q 3 | 101.7
PIC 📓🏠 | 宿題を家に置いてきました。 | 숙제를 집에 두고 왔습니다.
L 104.1 | ナ | 宿題を家に置いてきました。何と言いますか。 | 숙제를 집에 두고 왔습니다. 뭐라고 말합니까?
O 110.4 | | 1. すみません、宿題を置きますか。 | 죄송해요, 숙제를 둘까요?
O* 116.1 | | 2. すみません、宿題を忘れました。 | 죄송해요, 숙제를 잊어버렸어요(안 가져왔어요).
O 121.9 | | 3. すみません、宿題を家でしました。 | 죄송해요, 숙제를 집에서 했어요.
EXP 물건을 깜빡 두고 왔을 때 「忘れました(잊었어요)」라고 합니다.

Q 4 | 140.0
PIC 🔍🧒 | 田中君がいません。 | 다나카 군이 없습니다.
L 142.1 | ナ | 田中君がいません。何と言いますか。 | 다나카 군이 없습니다. 뭐라고 말합니까?
O* 147.3 | | 1. 田中君、いましたか。 | 다나카 군, (거기) 있었어요?
O 152.0 | | 2. 田中君、探しましたか。 | 다나카 군, 찾았어요?
O 157.1 | | 3. 田中君、行きましょうか。 | 다나카 군, 갈까요?
EXP 보이지 않는 다나카 군을 다른 사람에게 '봤는지(있었는지)' 묻는 1이 가장 자연스럽습니다. 3은 다나카 군 본인에게 하는 말이라 맞지 않습니다.
NOTE 책의 그림 없이 음성만으로 고른 정답입니다.
